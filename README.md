## 📖 Overview

**Personal Stock Analyst Agent** is an AI-powered financial analysis application that helps users analyze their stock portfolios through interactive dashboards and AI-generated insights.

Users can upload their stock transaction history, calculate portfolio performance using **FIFO accounting** and **XIRR**, visualize investment trends, and interact with an AI-powered financial assistant for portfolio analysis and recommendations.

---

## 🚀 Features

- 📂 Upload stock transaction history (CSV)
- 📊 Portfolio dashboard with key investment metrics
- 📈 Historical stock performance analysis
- 💹 FIFO cost basis calculation
- 💰 Realized and unrealized Profit/Loss analysis
- 📉 XIRR (Extended Internal Rate of Return) calculation
- 🥧 Portfolio allocation visualization
- 📅 Monthly investment activity
- 🤖 AI-powered financial assistant using **Groq Llama 3.3**
- 📡 Live stock market data using **yFinance**
- 📊 Interactive charts using **Plotly**

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sherishacv/Personal-Stock-Analyst-Agent.git
```

Go to the project folder

```bash
cd Personal-Stock-Analyst-Agent/stock-analyst
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
